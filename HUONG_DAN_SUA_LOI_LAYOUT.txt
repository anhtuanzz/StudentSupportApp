STUDENT SUPPORT - HƯỚNG DẪN SỬA CẢNH BÁO LAYOUT

1) Các cảnh báo Hardcoded text đã được sửa bằng cách chuyển mọi android:text, android:hint và android:contentDescription tĩnh trong 13 màn hình XML sang strings.xml.
2) Bỏ mục android:fontFamily=sans trong AppTheme (sử dụng font mặc định Android) để tránh chỉ định font không cần thiết trong giao diện.
3) Lỗi Cannot invoke InputStream.available() because assetStream is null thường xuất hiện trong Android Studio Layout Preview khi không đọc được font/tài nguyên từ SDK; KHÔNG khẳng định là lỗi Java/SQLite. Nếu vẫn thấy:
   - Trong màn hình XML chọn Design/Split, đổi Preview API sang API 35 (không chọn API 37 Preview nếu có).
   - Thử đổi Preview Theme sang một Theme.Material.Light mặc định.
   - Kiểm tra SDK Platform 35 qua SDK Manager; File > Sync Project with Gradle Files và Build > Rebuild Project.
   - Nếu build thành công nhưng Design vẫn lỗi: File > Invalidate Caches > Invalidate and Restart (nếu phiên bản Android Studio hiển thị tùy chọn này).
4) Nếu Build Output còn báo lỗi, hãy chụp toàn bộ dòng lỗi màu đỏ (không chỉ tab Problems trong XML).

Lưu ý: Bản này đã được kiểm tra cú pháp XML bằng công cụ phân tích XML, chưa biên dịch thử APK vì môi trường không có Android SDK.
